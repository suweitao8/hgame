# 新游戏（`new-game`）策划案总纲（GDD）

> 本文档为 `新游戏`（v0.1.0）的单一权威策划文档。**任何玩法、数值、系统或内容修改，必须先更新本文档与对应分卷文档，再改代码，并在实现后运行 `npm run check:design`、`npm test` 与 `npm run accept` 验证。**

## 1. 基础定位与核心循环

- **游戏 ID**：`new-game`
- **玩法原型（genre）**：`action-2d`（视角：`2d`，渲染器：`webgl2d`，物理：`none`，固定步频：`60 Hz`）
- **核心循环（Core Loop）**：`move-fight-upgrade-survive`
- **单局目标时长**：`180s`
- **设计纲领**：以紧凑的「移动/决策 -> 交战反馈 -> 成长选择 -> 波次升级/胜负结算」形成高反馈短局循环；禁止偏离核心体验的冗余外围系统。

## 2. 3C 手感与操作规格

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 移动速度 `playerSpeed` | `6.5 m/s` | 主角常规移动速率 |
| 碰撞半径 `playerRadius` | `0.45 m` | 角色受击与体型判定半径 |
| 冲刺速度 `dashSpeed` | `16 m/s` | 瞬时位移爆发速度 |
| 冲刺冷却 `dashCooldownSec` | `1.4 s` | 冲刺技能冷却间隔 |
| 顿帧时长 `hitStopMs` | `36 ms` | 暴击/重击停顿感 |
| 最大震屏 `traumaMax` | `0.55` | 相机创伤抖动上限 |

## 3. 核心数值平衡与黄金三角

| 指标 | 当前值 | 设计约束 / 依据 |
| --- | --- | --- |
| 玩家生命 `playerHp` | `100` | 抗击打次数 `8.3` 次（建议 `3~25` 次） |
| 基础怪生命 `gruntHp` | `30` | 基准 TTK `1.07s`（建议 `0.1~5.0s`） |
| 基础怪伤害 `gruntDamage` | `12` | 每次接触/攻击伤害 |
| 有效输出 `weaponDps` | `28` | 初始武器基准秒伤 |
| 场地跨度 `arenaSpan` | `48 m` | 穿场时间 `7.4s`（建议 `6~40s`） |
| 单波时长 `waveDurationSec` | `60 s` | 基础波次节奏 |

## 4. 成长、经济与胜负规则

- **核心货币**：`gold`（初始 `0`）
- **升级卡池上限**：`5` 项（每次最多展示 `3` 张卡）
- `atk-up` · **⚔️ 锐刃**：+25% 伤害 / -5% 移速
- `spd-up` · **⚡ 迅捷**：+20% 攻速 / -10% 护甲
- `hp-up` · **♥ 生机**：+30 生命 / -5% 暴击

### 波次基线
- `wave-1`：时长 `60s`，刷新率 `1.5/s`，敌种 `grunt, runner`

- **胜负与重开**：玩家生命归零进入 `result` 结算并持久化最高分（`createVersionedStore`），点击「再来一局」无刷新重置状态。
