# 新游戏（`new-game`）关卡与地编设计文档

> 本文档定义 `新游戏` 的空间尺度、出生点与刷怪拓扑、碰撞分离原则及波次推进节奏。调整地图结构、障碍物或刷怪区域前，须同步更新本文档与关卡数据文件。

## 1. 空间尺度与坐标约定

- **渲染维度**：`2d`（固定步频 `60 Hz`）
- **逻辑场地跨度（arenaSpan）**：`48 m`（中心为原点 `(0, 0)`，有效活动半径约 `24.0 m`）
- **单位规范**：逻辑数值统一采用 SI 制（米 / 秒 / 弧度）；2D 渲染映射时显式标定像素换算比例，禁止将像素坐标混入策划数值。

## 2. 地形、障碍与碰撞分离

- **视觉与碰撞分离**：表现层几何/贴图/材质（如 `model-slots.json`、装饰网格）不得直接充当权威碰撞或寻路依据；物理碰撞与障碍阻挡必须在关卡数据（如 `level.json`、`TileMap` 或 `createHeightfieldTerrain3D`）中显式声明。
- **可达性约束**：任何带有障碍物或房间/通道的地图修改后，必须使用 `check-level.mjs`（`npm run check:level`）确保出生点到所有关键点 `100%` 连通且无孤岛。

## 3. 出生点、刷怪区与触发拓扑

- **玩家出生点**：场地中心 `(0, 0)`，开局保证安全视野与缓冲半径。
- **敌人刷新环带**：围绕玩家外围安全环带生成（避免贴脸瞬杀；首波接敌反应时间 `>= 2.5s`，线防御 `>= 6.0s`）。

## 4. 锯齿波次节奏、机制递进与轻度过场短语

- **锯齿波次与旗帜高潮**：波次强度遵循「起势预热 → 爬坡施压 → 喘息低谷（`breatherSec >= 4`）→ 旗帜高潮（`flag: true`）」，禁止第 1 波即达峰值或全程平推。
- **单关新机制与硬克制**：每关引入 `<= 2` 个新机制（`> 3` 报错）；含水路、飞行、盾牌等词条的关卡须确保 `availableTools` 存在对应克制解。
- **轻度过场短语（PvZ 戴夫式）**：`barks` 单关 `<= 3` 条、单行 `<= 24` 字、非阻断提示；配合 `kit/stage-architect.js` 的 `createStageDirector` 运行 60Hz 波次。
- **波次与事件编排**：
- `wave-1`：时长 `60s`，刷新率 `1.5/s`，敌种 `grunt, runner`
