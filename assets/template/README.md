# HGame Game Project

This is a self-contained game project generated by HGame. The selected runtime profile and optional modules are recorded in `engine.config.json`; the Host-facing metadata is in `game.config.json`.

## Project files

- `src/main.js`: profile entry point.
- `src/`: game rules, systems, and presentation code.
- `vendor/hgame/`: local runtime copy; no CDN is required.
- `assets/vendor/three/`: Three.js files copied only for 3D projects.
- `engine.config.json`: HGame profile, renderer, physics backend, tick rate, and features.
- `game.config.json`: game ID, display name, entry page, and optional Host metadata.

Keep game rules and authoritative state separate from UI and renderer objects. Use semantic game actions rather than embedding gameplay rules in DOM or Three.js callbacks.

## Preview and tests

Use the HGame repository's `scripts/preview.mjs` or another local HTTP server to serve this directory. Do not open ES modules through `file://`. Run the included tests with:

```powershell
npm test
npm run check
```

The 2D and 3D examples use keyboard movement; the UI example advances only in response to commands. Extend input adapters and browser/device tests when the actual game requires touch, gamepad, or multi-pointer controls.

## 3D starter data

The 3D profile includes editable level, material, and model-slot data. World-aligned material scale defaults to one world unit. Model replacements preserve their logical slot; visual changes must not change gameplay collision or simulation rules.
