# TapTap 小游戏和三端 SDK 实施计划

**目标**　在现有小游戏导出链路加入 TapTap，并让微信、抖音和 TapTap 可使用同一套登录、分享和激励视频接口。

**实现**　保持 `start(host)` 入口，新增 `taptap` 平台的 `tap` 宿主及包体配置，在 `host.sdk` 暴露带能力检测的客户端 SDK 和原生 API。

- [x] 先增加 TapTap 样板打包和无 DOM 宿主测试，再为现有打包器加 `package:taptap`、TapTap AppID 和包体限制。
- [x] 先用模拟宿主固定三端 SDK 行为，再实现登录凭证、登录态、本地启动参数、分享状态与激励视频结果。
- [x] 核对 TapTap 官方格式并验证目录与 ZIP。更新生成项目命令和接入指南。`npm run check` 通过 813 项测试，交付到当前 `main`。

登录凭证交换由游戏服务端负责。验证覆盖本地构建和模拟宿主，平台预览、上传及真实广告属于有账号和配置的验收环节。
