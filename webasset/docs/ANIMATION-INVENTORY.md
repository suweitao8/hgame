## 四、整体评估：目前缺少什么动画？

当前库在**武士刀/单手剑/双刀/长枪/重锤/镰刀、徒手武术（拳击/泰拳/咏春/高速连击）、法术、潜行处决、坐卧日常、商业 NPC** 上非常充沛；但在以下领域存在明显缺口，按游戏开发高频度分优先级列出：

### P0 · 核心战斗与通用移动高优缺口

1. **现代长枪械与战术射击全套（严重缺失）**
   - **现状**：`弓箭与枪械` 共 289 条，但其中 **219 条是弓箭**（`GhostSamurai_Bundle`），实际现代热兵器只有 **66 条手枪**（`PistolAnimsetPro` + `Female_Animations`），`rifle / shotgun / sniper / smg` 相关动作几乎为 0（仅 3 条误归或手枪/左轮换弹）。
   - **缺少**：步枪/突击步枪、霰弹枪、狙击枪、冲锋枪、重机枪/火箭筒的持枪待机、举枪瞄准（8 向移动）、开火/后坐力、站姿/蹲姿换弹、切枪、近战枪托砸击、手雷/闪光弹战斗投掷。
2. **剑盾 & 双手大剑 / 战斧冷兵器体系（空白）**
   - **现状**：太刀/单手剑/双刀/长枪/锤/镰刀齐全，但**盾牌相关（`shield` / `buckler`）为 0**，**双手大剑（Greatsword / Claymore）为 0**，**战斗用单手斧/双持战斧为 0**（仅 1 条砍树伐木斧）。
   - **缺少**：剑盾举盾待机/移动/受击、盾击、弹反；双手重剑慢速蓄力横扫/砸地/架招；战斧劈砍与狂战士连招。
3. **垂直爬梯子（Ladder）与高空滑翔/降落（空白）**
   - **现状**：`ClimbingAnimationSet` 与 `ParkourAnimations` 偏向自由跑酷/挂墙攀岩，**`ladder` 爬梯子为 0 条**；空中仅限法师悬浮与恶魔飞行。
   - **缺少**：上下直梯/软梯（进梯、爬升、下降、滑梯、梯顶翻出）；自由落体、滑翔伞/翼装滑翔、开伞减速与高空着陆。
4. **游泳与水中动作体系（极度薄弱）**
   - **现状**：仅 `PhoenyxAnimPack3` 提供 4 条基础游泳循环（踩水、水面游、水下潜游），缺乏完整状态机。
   - **缺少**：跳水入水、涉水/浅水行走、水面冲刺游、水下转向上浮/下潜、水下攻击/交互、攀爬上岸、水中溺水/受击。

### P1 · 玩法扩展与世界生态重要缺口

5. **骑乘与非汽车载具（空白）**
   - **现状**：`CarInteractAnimations_VOL1` 仅 22 条且全部围绕四轮轿车门/座椅交互；**骑马/坐骑相关为 0 条**。
   - **缺少**：上马/下马、骑乘待机/慢步/小跑/疾驰/跳跃、马背弓箭/劈砍；摩托车/自行车骑行、划船、操作固定炮台/机甲驾驶舱。
6. **正常人类战术匍匐（Prone）与掩体系统**
   - **现状**：现有 35 条 `Crawl` 几乎全部来自 `ClassicFemaleGhost`（女鬼爬行），不适用于正常玩家角色。
   - **缺少**：立/蹲转卧倒、人类俯卧待机/前后左右爬行、卧姿翻滚、卧姿瞄准射击、贴墙掩体盲射与探头切换。
7. **受伤、异常状态与硬直反馈**
   - **现状**：`Injured / Limp` 仅 2 条（`Anim_Walk_Injured`、`Front_Injured_Idle`）。
   - **缺少**：低血量跛行待机/慢走/捂腹逃跑、中毒咳嗽、眩晕晃动、触电抽搐、着火拍打、冰冻定身、被捆绑/眩晕倒地挣扎。
8. **非人形怪物 / 野生动物 / 大型 Boss（生态单一）**
   - **现状**：7 个怪物/生物包（`Zombie_Anims`、`Demon_Anims`、`ClassicFemaleGhost`、`Ghost_Creature_Anims`、`Creatures_animations`、`Animations_Creature`、`41_Animations_Monsters`）共 510 条，多为类人形骷髅骨架（`channelCount` 约 204–267）。
   - **缺少**：四足兽（狼/狗/熊/鹿/坐骑马）、大型四足/多足 Boss（巨龙、蜘蛛、魔像的扫尾/喷吐/践踏/破防虚弱跪地）、飞行鸟兽/飞虫、小型宠物。
9. **生活经营与模拟向细分动作**
   - **现状**：伐木/挖矿/修理/酒保/服务员较多，但田园/医疗/现代休闲偏少。
   - **缺少**：
     - **农耕与牧场**：翻土锄地、播种撒种、提桶浇水、镰刀收割、挤奶/喂食动物。
     - **烹饪与店铺**：颠勺炒菜、切菜、端盘上菜、收银结账。
     - **医疗救援**：目前只有 1 条腿部绷带包扎与 4 条战地拉起/注射，缺少心肺复苏、背负伤员、给他人治疗。
     - **休闲文化**：乐器演奏（吉他/钢琴/鼓/笛子，当前 **0 条**）、体育运动（仅 2 条魔法足球，缺投篮/踢球/挥拍/游泳跳水）、拍照/举相机。

### P2 · 管线工程与分类整理建议

10. **8 向原地移动（In-Place）标准化矩阵与起停衔接**
    - **问题**：全库 `5,417` 条未在文件名显式标明 `IP` 或 `RM`；不同武器包的 8 向走/跑/蹲走/持械瞄准走完整度不一，且 `PreacherAnimations`（最长 119s）、`Pedestrian_Walks_01`（最长 89s）等包含超长序列不适合直接进战斗混合树。
    - **建议**：梳理一套标准 8 向 In-Place 基础移动对照表（待机 / 走 / 跑 / 冲刺 / 蹲走 / 跳跃起落），确保每个主力武器流派都有完整 `Idle + 8-Way Walk/Run + Hit + Death`。
11. **WebAsset 分类清洗项**
    - `其他动作` 中有 **61 条**（全来自 `CLazyAnimpack`），主要是 `Mvm_JogStart/Stop`（走跑急停）、`LoWall_*`（贴墙冲刺）、`Wall_LBootJump`（蹬墙跳）、`Esc_Spawn`（出生），建议拆分归入「跑/走/攀爬跑酷/闪避」。
    - `SittingAnimations` 中部分 `AIM_ground_aim_*` 被误归入「席地盘坐与台沿坐」，可核对后重分类。
    - `弓箭与枪械` 混合了 219 条冷兵器弓箭与 66 条热兵器手枪，若后续补充步枪，建议在 WebAsset 中拆分为 **「弓箭」** 与 **「枪械射击」** 两个独立分类。
    - `0.07s` 的单帧定格（58 条）可在列表加徽标提示（如 `Pose`），避免预览时误以为动画卡住。

## 五、附录：HGame 运行时动画系统模块（代码层参考）

除上述 3D 骨骼动画资产库外，HGame 引擎自身在 `assets/runtime/` 中已内置以下动画子系统，可直接驱动游戏内播放与优化：

| 模块路径 | 能力定位 | 说明 |
|---|---|---|
| `assets/runtime/animation/animator3d.js` | 3D 骨骼动画状态机 | 支持 StateMachine、1D/2D BlendTree、Avatar Mask 上下半身遮罩、动画事件、双骨解析 IK 与 LookAt IK |
| `assets/runtime/animation/retarget3d.js` | 3D 骨骼重定向 | 用于将 Unreal 标准骨骼动作重定向至自建低模角色骨骼 |
| `assets/runtime/integrations/model3d/bone-vat.js` | GPU 骨骼 VAT 群集动画 | 支持将动作烘焙为 `.vat.bin`（HalfFloat Bone-VAT + 3-LOD），支撑千至万级 3D 单位同屏动画 |

| `assets/runtime/animation/skeleton2d.js` | 2D 骨骼动画 | 轻量 2D 骨骼层级动画 |
| `assets/runtime/ui/ux-motion.js` | UI 动效编排 | 提供交错入场、弹簧阻尼等界面微动效 |
