# 角色图片生成待办与专属提示词

> 根据角色库自动生成；更新角色资料或生成状态后，运行 `npm run prompts:export` 刷新本文件。
> **标准传递：** 生成影视图时输入全部原始参考图；生成模型图时只输入当前影视 AI 定稿图，不得混入原始参考图。没有影视图时先生成影视图。
> 两种形态统一使用纯色哑光深灰背景 RGB(51, 51, 51) / #333333，禁止白色、浅灰、透明背景。
> **纯角色规则：** 所有武器、道具、食物、工具、手持物及周边独立物件均不得进入生成图；角色资料中的道具字段仅供文字设定参考，不参与生图。

## 一、默认形态 · 六视图

> 用于影视角色细节展示。每张图严格 2:1 横向、四栏六视图，统一深灰背景；只展示角色本体，不出现武器或道具。

## 二、模型参考 · 双视图

### 两种图通用的表情验收

影视六视图与建模双视图统一使用闭嘴的中性静息表情。嘴唇或上下颌自然合拢，嘴角放松，眉眼自然，禁止露齿、张嘴、嘟嘴、笑、皱眉或瞪眼。参考图已有表情时，只继承外观。入库前放大检查所有看得见口部的头部特写和全身视图，发现表情偏差先修图再复查。

### 服装、握姿与入库验收

手动使用 ImageGen 时，使用 WebAsset 的对应模式提示词作为完整底稿，再追加角色特征。影视图完整还原参考服装，包括斗篷、原裙长和袖口。以下服装修整与站距要求只用于建模图，生成前与影视定稿对照。

- 斗篷、披风和背后拖尾布片完整移除。猫咪骑士保留金属护甲和猫尾。
- 长裙和过膝裙改成膝上短裙，保留配色与材质，露出膝盖、小腿和鞋。保持原有袖型、袖长、蓬度和褶皱，只把宽大的腕部袖口收成普通窄袖口。
- 正面双脚平行、自然分开，脚内侧约留一只脚掌或靴子的宽度。以腿部轮廓清楚、站姿自然为准，避免近乎并拢或大幅岔腿。侧面从同一站姿投影。
- 按原图和定稿逐图对照面部、服装、站距和握姿，再核对完整轮廓及正侧对齐。局部不符就只修该处并复查。若任务要求提高分辨率，核对生成文件的像素尺寸。验收通过后再上传，因为上传会替换同类型旧图。

1. 先确认影视定稿。建模图只使用同角色的影视定稿作为外观参考，生成正面和严格侧面的全身 T 姿势。
2. 人形手统一空手虚握。四指向掌心弯曲、拇指轻扣食指侧，拳背朝上、握口朝下。正面双手与侧面近侧手保持同一握姿。猫狗等角色保留原有圆收兽爪，爪心朝下。
3. 入库前放大检查正面左右手和侧面近侧手。人形手出现摊掌、伸指、手腕下垂、遮挡或裁切，或两个视图握姿不一致时，按影视定稿修正并复查。远侧手可因正交投影自然重合。
4. 同时确认两视图的头顶、足底和手臂高度对齐。通过后再保存为「模型」正式图，并从角色库打开核对。提示词检查只能验证要求已写入，成图仍须目检。

> 用于 3D 角色建模。只以影视 AI 定稿为唯一外观标准，必要时转换为直立两足人形；左侧全身前视图，右侧严格 90° 侧视图；只展示角色本体，不出现武器或道具。
