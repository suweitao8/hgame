# 逆向效率工作流参考

> **权威入口**：标准一键流程见 `SKILL.md`（`npm run re:forge` / `extract-fast.mjs` → `export-clean-spec.mjs` → `validate-spec.mjs`）。本文保留批次推进依赖顺序参考。

## 阶段顺序：程序 → 策划 → 资产 → 装配 → 集中验证

1. **程序（最高优先级）**：先从入口、状态机、公式、AI、事件与存档梳理调用链与数据读取契约；源码/配置已回答的问题不重复抽帧视频。
2. **策划**：按程序确认的 Schema 批量提取关卡、角色、敌人、物品、数值、波次与奖励；同一源版本与已校准解析器直接批量运行。
3. **资产**：渲染、骨骼、物理、寻路、粒子、合成音效优先标 `hgame-fallback` 由 HGame 原生模块接管，仅记录语义槽位，不逆向底层 Shader/复杂光照。
4. **装配与集中验收**：第一阶段装配完成后标为 `implemented/unverified`；第二阶段统一跑静态检查、单测、生产构建与真实浏览器操作验收。
5. **并行纪律**：同一阶段内仅对互不冲突的批次并行；共享入口、`coverage.csv` 与总 manifest 保持单写者。
